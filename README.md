# Mongolian Matrix Screensaver

A small native macOS Matrix-style screensaver animation using individual Mongolian traditional script Unicode characters.

## Build

```sh
./build.sh
```

The build produces:

- `build/Mongolian Matrix Screensaver.app`
- `build/bin/matrix-mongolian`

## Run

```sh
open "build/Mongolian Matrix Screensaver.app"
```

or run the executable directly:

```sh
./build/bin/matrix-mongolian
```

Press `Esc`, press `q`, or click the screen to quit.
